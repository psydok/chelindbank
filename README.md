Необходимо реализовать проверку контрольного числа СНИЛС на PL/SQL или PL/pgSQL. Пакет с перегруженными функциями для различных вариантов использования. В том числе реализовать процедуру массовой проверки валидности СНИЛС в многопоточном режиме.
Предполагать использование разработанного модуля как при предварительной валидации ввода, так и при работе на стороне БД (триггер/процедура).
